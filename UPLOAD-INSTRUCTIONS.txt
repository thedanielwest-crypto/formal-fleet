HOW TO UPLOAD (GitHub website)
1. Open github.com/thedanielwest-crypto/formal-fleet
2. Add file -> Upload files
3. Drag in the CONTENTS of this folder (the app, components, lib and supabase
   folders plus package.json, package-lock.json and tsconfig.json).
   GitHub keeps the folder paths and replaces matching files.
   Don't upload this instructions file.
4. Commit message: "Owner Academy" -> Commit changes
5. Netlify rebuilds in a couple of minutes.

TO TURN ON ALERT EMAILS (one-off, about 15 minutes)
Alerts already show in Admin > Owner Academy. To also email them to
admin@fleetformal.com.au:
1. Sign up free at resend.com.
2. Domains -> Add domain -> fleetformal.com.au, then add the DNS records it
   shows at your domain provider.
3. API Keys -> Create API key -> copy it.
4. Supabase -> Edge Functions -> Secrets -> add RESEND_API_KEY = (your key).
5. In Admin > Owner Academy, click "Retry emails" to send anything waiting.

BOOKING LOCK
Off by default, because no car is linked to a fully trained owner yet.
Turn it on in Admin > Owner Academy once your BEA is approved and owners are
verified. When on, a car can't be invited to an event or enquired about
until its owner has all 12 steps verified.
